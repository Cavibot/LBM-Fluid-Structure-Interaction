# HOME 重建、隔离验证与可视化对照计划

本文定义暂停现有几何 HOME-Free 路径之后的下一阶段工作。目标不是继续在旧组合上修补参数，而是把 HOME、论文 HOME-Free、几何 VOF/PLIC、Courant 投影、拓扑、动量输运和 FSI 分层隔离，先证明单项，再通过严格消融逐层组合。

每个阶段必须同时交付数值证据和视觉证据。单元测试通过但没有可检查画面，或者画面合理但缺少守恒与稳定性记录，都不能视为完成。Dam-break 是贯穿自由表面阶段的统一观察场景，用来直观比较不同算法到底改变了什么。

本项目面向视觉仿真和潜在游戏应用，不把机器精度意义上的绝对守恒作为所有场景的唯一目标。严格审计用于发现算法错误；最终候选允许在误差有界、修正透明且没有明显非物理伪影的前提下，在数值精度、视觉效果、稳定性、显存和运行时间之间做明确权衡。

## 1. 范围与原则

1. 现有 `wanphys/_src/fluid/fluid_grid/home_lbm/` 保持冻结，用作历史结果和失败基线；新工作不在其中继续叠加修正。
2. 官方 Home-FSLBM 只做轻量冒烟验证。它的旧 C++/CUDA/OpenCV 环境不作为本项目的长期研发环境。
3. 官方 GPLv3 源码保持为外部参考程序，不直接复制进 WanPhys。新 Warp 实现依据论文公式独立实现，并用公开源码核对调度、变量语义和结果趋势。
4. HOME 单体阶段只求解单相流，不伪装成自由表面，也不使用 Dam-break 作为单相 HOME 的物理证明。
5. 论文 HOME-Free 基线先忠实采用 link-wise mass exchange、气压边界和原始 topology，不加入 PLIC 输运、Hodge 投影、扩展动量账本或 FSI。
6. 每次组合只允许增加一个可辨认的新模块。新增模块导致失败时停在该层，不继续向上叠功能。
7. 可视化只读取提交态，不能回写 moments、fill、质量、速度、压力、topology 或刚体状态。
8. 不以“没有崩溃”代替正确性，也不以“图片好看”代替数值验收。
9. 不因追求极小残差而无条件接受数倍性能损失。每项高精度机制必须同时报告其视觉收益、误差收益和时间/显存成本。
10. 允许为视觉生产使用有界、显式、可审计的稳定化、局部修正或较宽容差；隐藏修正、无限累积修正和掩盖算法爆炸的修正仍不允许。

## 2. 隔离边界

建议新实现使用以下边界：

```text
wanphys/_src/fluid/fluid_grid/home_rebuild/
├── core/                   # 纯 HOME-LBM：十矩、重构、碰撞、受力和边界
├── free_surface_fsl/       # 论文忠实 HOME-Free/FSLBM
├── geometric_vof/          # 独立 PLIC、Weymouth-Yue 和解析速度场测试
├── fsi/                    # 独立 HOME/自由表面 FSI
├── visualization/          # 只读切片、表面、图片和 manifest 输出
└── compositions/           # 唯一允许组合上述模块的位置

wanphys/examples/lbm/home_rebuild/
├── home_core/              # 单相 HOME 演示
├── home_free_fsl/          # 论文 HOME-Free 演示
├── geometric_vof/          # 几何输运演示
└── comparisons/            # 固定场景横向比较

newton/tests/home_rebuild/
├── core/
├── free_surface_fsl/
├── geometric_vof/
├── fsi/
└── integration/
```

依赖方向固定为：

```text
core <----- free_surface_fsl
  ^               ^
  |               |
  +------ compositions <------ geometric_vof
                 |
                 +------------ fsi
```

`core` 不得依赖任何自由表面或 FSI 模块；`geometric_vof` 必须能在规定的解析速度场下独立运行；所有研究性组合必须拥有不同的显式类型和入口，不能用隐藏开关改变同一个公共求解器的语义。

## 3. 统一交付契约

每次正式场景运行保存一个独立目录：

```text
run-directory/
├── manifest.json           # 代码、环境、算法、物理量和输出配置
├── metrics.csv             # 每个采样时刻的数值指标
├── run.log                 # 完整日志和失败原因
├── checkpoints/            # 可选的恢复状态
├── fields/                 # 精简数值快照或其校验清单
├── frames/                 # 干净演示图片
├── audit_frames/           # 带时间和关键指标的审计图片
└── contact_sheet.png       # 覆盖全过程的拼图
```

`manifest.json` 至少记录：

- Git 提交和工作树标识；
- 算法包、碰撞模型和自由表面后端；
- GPU、驱动、CUDA、Warp 和 Python 版本；
- 网格、`dx`、`dt`、黏度、重力、表面张力和边界；
- Reynolds、Froude、Weber、Mach 和最大 Courant 数；
- 初始几何、随机种子、相机和渲染参数；
- 是否启用裁剪、限速、fallback、投影或事后修正。

任何隐藏限速、未记录 fallback 或未记录修正都会使该次结果失去验收资格。显式稳定化和修正必须记录触发次数、累计修正量、影响区域和关闭该机制时的对照结果。

### 3.1 三档运行与验收配置

每个可运行算法提供三个显式档位。三档使用同一物理场景和输出协议，但目标不同：

| 档位 | 目的 | 数值与修正策略 | 视觉和性能要求 |
|---|---|---|---|
| `audit` | 小网格算法审计、定位错误 | 最严格残差；尽量关闭限速和事后修正；保存完整账本 | 允许较慢，画面主要用于核对异常位置 |
| `balanced` | 最终演示和游戏型候选 | 允许有界局部稳定化、有限迭代和适度守恒误差；全部量化记录 | 画面可信、全过程稳定，性能和显存必须可接受 |
| `preview` | 参数搜索和尽早观察效果 | 更低分辨率、更少迭代和较宽容差；不能用于最终物理结论 | 快速出图，允许可见离散误差，但不能数值爆炸 |

`audit` 是参照尺，不自动成为最终默认；`balanced` 是最终候选的主要比较档；`preview` 只用于缩短反馈周期。算法排名至少同时展示：

- 全程相对质量漂移及其时间趋势；
- 总动量/能量偏差及外力闭合趋势；
- 最大速度、Mach、Courant 和异常单元数；
- 局部/全局修正的累计量及其占代表质量或动量的比例；
- 前沿位置、撞墙时间、最高液面和回落形态；
- 每步耗时、输出一帧所需时间、峰值显存；
- 视觉缺陷清单，包括底部真空层、过度圆滑、网格噪声、非物理水花和体积缩涨。

数值误差采用“硬底线 + 候选排序”而不是单一极限：NaN、负密度、指数速度增长、持续加速的漏水和非法拓扑属于硬失败；在硬底线以内，守恒更好是优势，但要与可见效果及性能成本共同排序。具体容差由 R2/R3 的基线扫描确定并写入场景配置，不能在看到某次最终结果后临时放宽。

## 4. 统一可视化门槛

### 4.1 图片不是可选附件

每个算法阶段至少输出：

1. 一张能够确认场景已经有效推进的代表图；
2. 一张覆盖开始、发展和结束的时间序列拼图；
3. 对 Dam-break，输出至少六个真实物理时刻的独立图片；
4. 同一阶段有多个算法候选时，输出固定时刻并排对照图。

Dam-break 默认采样物理时刻为总时长的：

```text
0%, 15%, 35%, 60%, 85%, 100%
```

若撞墙、最大爬高或回落发生在这些时刻之外，额外保存事件帧，不能用重复帧或插值帧代替真实模拟状态。

### 4.2 对照条件必须固定

横向比较必须固定：

- 水槽和液柱物理尺寸；
- 无量纲参数；
- 网格分辨率与时间采样；
- 相机位置、焦距、裁剪范围；
- 水材质、灯光、色调映射和容器显示方式；
- 表面提取阈值和平滑参数。

若算法状态不同，例如 link-wise HOME-Free 与 PLIC 对 fill 的定义不同，应在 manifest 中说明转换方法。显示层不能为某个算法单独使用更强平滑来掩盖缺陷。

### 4.3 各阶段推荐显示量

| 阶段 | 主要图片 | 辅助图片 |
|---|---|---|
| 官方 Home-FSLBM | 官方 mass/phi PPM | velocity PPM |
| 单相 HOME | 涡量、速度或被动染料切片 | 密度扰动、能谱图 |
| 论文 HOME-Free | `fill=0.5` 自由表面 | fill 切片、速度切片 |
| PLIC 独立包 | 初始/最终界面轮廓 | 体积误差热图 |
| HOME-Free 对照 | 固定视角 Dam-break 表面 | 同时刻 fill/速度切片 |
| FSI | 自由表面加刚体 | 力、轨迹和切格诊断 |

实时 ViewerGL 可以作为快速调试工具，但不是依赖项。远端无桌面时必须能以 headless 方式输出同样的固定图片。

## 5. 阶段 R0：冻结旧实现

1. 保存现有几何 HOME-Free 的成功测试、低黏度失败日志和 Dam-break 图片。
2. 固定一组旧实现的 `nu=0.10` 和 `nu=0.04` 结果作为视觉反例。
3. 记录旧路径中的 PLIC、投影、拓扑、动量账本和 FSI 开关。
4. 后续新实现不复用旧组合模块，只允许使用这些结果作比较。

完成证据：旧结果拥有 manifest、关键指标和全过程拼图，可以在最终对照中标为 `legacy-geometric`。

## 6. 阶段 R1：官方 Home-FSLBM 冒烟

本阶段只回答“官方公开程序能否在可接受成本下启动并产生结果”。

1. 固定官方提交 `4311560`。
2. 在可用 NVIDIA 机器上尝试原样配置，5090 使用支持 Blackwell 的 CUDA，并显式指定目标架构。
3. 只运行二维泡沫默认入口的短程版本，目标为几十个输出帧，而不是完整论文复现。
4. 保存至少三张 mass/phi 图、一张速度图和运行日志。
5. 检查程序没有立即出现 NaN、CUDA fault 或空白输出。
6. 若旧 OpenCV/CUDA 构建问题超出少量兼容调整，记录阻塞并结束本阶段，不为参考程序重建完整旧环境。

完成门槛：能够确认官方算法实际推进并输出非空图片；若环境阻塞，则以明确的构建诊断关闭，不阻塞后续独立实现。

## 7. 阶段 R2：纯 HOME-LBM

R2 不包含空气、VOF、自由表面或移动刚体，目标是确认 HOME 核心的正确性、低黏度稳定性、视觉流动结构和真实性能收益。

### R2.1 数学与局部算子

- D3Q27 权重、速度和反向索引；
- 十矩与三阶 Hermite 分布重构；
- 质量和动量守恒矩；
- NOCM-MRT 碰撞及高阶受力；
- CPU oracle、Warp CPU 和 CUDA 对齐；
- 非有限状态、非法松弛率和超 Mach 硬失败。

### R2.2 解析和标准流动

- 周期均匀平移；
- Couette flow；
- Poiseuille flow；
- 剪切波衰减；
- Taylor-Green vortex；
- 障碍物绕流或周期剪切层。

### R2.3 低黏度与性能扫描

按无量纲目标和 Mach 限制设计黏度扫描，至少覆盖从温和黏度到论文量级低黏度的多个点。记录误差、能量衰减、峰值速度、稳定步数、MLUPS、显存和 kernel 资源，不能只记录“通过/失败”。

### R2.4 视觉交付

- Taylor-Green：六个时刻的涡量或速度切片；
- 剪切层：被动染料或涡量卷起过程；
- 障碍物绕流：尾涡形成和脱落图；
- 至少一张固定视角代表图和一张全过程拼图。

完成门槛：`audit` 档的解析误差和收敛符合预期；`balanced` 档若使用稳定化或修正，其规模必须有界并有关闭机制的对照；画面保持应有对称性并出现合理涡结构；明确量化 HOME 相对完整 PDF 基线的显存、速度和视觉收益。

## 8. 阶段 R3：论文忠实 HOME-Free

R3 只组合 HOME core 和论文 FSLBM 路径：

```text
HOME 十矩
+ link-wise mass exchange
+ mass/fill/LIQUID-INTERFACE-GAS
+ excess mass redistribution
+ missing-population gas-pressure boundary
+ fresh/dead cell initialization
+ 论文原始 topology
```

本阶段禁止 PLIC 质量输运、Courant/Hodge 投影、`excess_momentum`、全局速度修正、移动固体和旧几何 topology。

实施顺序：

1. 静止和平移平面界面；
2. 静水压力与自由表面边界；
3. 拓扑转换和多余质量重分配；
4. Laplace 气泡；
5. 二维/薄三维液柱坍塌；
6. 完整三维 Dam-break、撞墙和回落。

Dam-break 必须跑到前沿撞击对侧墙并进入明显回落阶段，不能在“正在向对侧运动”时结束。输出六个固定物理时刻、撞墙事件帧、最大爬高事件帧和最终状态。

完成门槛：质量、速度、界面状态和压力诊断通过；低黏度场景不发生指数增长；全过程图片不存在整齐真空层、悬浮底隙、容器外水体或错误圆角初始化。

## 9. 阶段 R4：独立几何 VOF/PLIC

R4 不读取 HOME moments，首先在规定的离散无散度速度场下独立验证：

- PLIC 平面体积反演；
- Parker-Youngs 法向；
- 轴向、斜向和旋转输运；
- Weymouth-Yue 方向分裂；
- 周期往返和平移；
- 不同 Courant 数和网格分辨率；
- 体积守恒、界面形状误差和收敛趋势。

视觉交付包括初始/中间/最终界面轮廓、误差热图和全过程拼图。独立 PLIC 不通过时，禁止接入 HOME。

## 10. 阶段 R5：Dam-break 消融组合

使用 R3 已验收的同一个 Dam-break 场景，依次生成：

| 变体 | 唯一新增内容 |
|---|---|
| `FSL` | 论文 HOME-Free 基线 |
| `FSL+PLIC-geometry` | PLIC 只做几何、曲率和显示，不改变质量输运 |
| `HOME+GVOF` | 几何 VOF 替换质量输运，不加投影 |
| `HOME+GVOF+projection` | 增加 Courant/Hodge 投影 |
| `HOME+GVOF+topology` | 增加几何 topology |
| `HOME+GVOF+momentum` | 使用同一面质量通量推导局部动量通量 |

每个变体都必须重复同样的全过程 Dam-break。比较图片采用矩阵布局：行表示算法，列表示固定物理时刻。同步比较前沿位置、最高液面、撞墙时间、质量误差、峰值速度、Mach、动能和运行时间。

动量账本首先用于审计。若几何质量通量为 `F_m`，动量更新应优先从一致的面速度推导。`audit` 档禁止用全局均匀速度补偿掩盖局部不一致；`balanced` 档如确有必要采用有限补偿，必须设累计预算、单步上限和触发告警，并用并排结果证明它改善了稳定性或视觉效果，而不是仅让总量看似闭合。

任何新增变体在数值或视觉上退化，都停留为研究分支，不进入下一组合。

## 11. 阶段 R6：FSI 分层接入

FSI 按以下顺序独立推进：

1. 单相 HOME + 固定物体；
2. 单相 HOME + 规定运动物体；
3. 单相 HOME + 双向刚体；
4. 论文 HOME-Free + 固定物体；
5. HOME-Free + 单向 entry/exit；
6. HOME-Free + 双向作用反作用；
7. Dam-break 撞击可移动物体。

最终 FSI Dam-break 继续使用相同水槽、液柱、相机和时间采样，并额外记录刚体轨迹、速度、角速度、流体/刚体作用反作用残差、wet/dry links、fresh/dead cells 和总动量。

完成门槛：刚体运动与载荷方向合理；没有穿透、悬浮水层或切格质量跳变；数值账本与图片中的撞击、推进、回落过程相互一致。

## 12. 统一失败处理

一次运行出现以下任一情况即判为失败，并保留最后一个有效快照和失败图：

- NaN、Inf、负密度或非法 fill；
- Mach/Courant 超出该场景声明范围；
- 质量或动量误差持续单向增长；
- 峰值速度呈指数增长；
- 直接液体-气体非法邻接；
- 依靠未声明裁剪、限速、fallback 或补偿继续推进；
- 已声明修正超过该档位的累计预算，或者修正量持续加速增长；
- 图片为空、相机看不到容器/液体，或六个固定时刻不完整；
- 算法之间使用了不同物理时长、相机或显示参数却仍声称可以横向比较。

失败后只修改当前新增层，先重跑该层的最小单元和短场景，再恢复完整 Dam-break。禁止同时修改多个模块后用最终画面猜测原因。

## 13. 阶段完成定义

每个阶段只有在以下四项同时存在时才关闭：

1. **实现**：独立包和显式入口；
2. **数据**：自动测试、场景指标和环境清单；
3. **画面**：代表图、全过程拼图和必要的事件帧；
4. **结论**：说明该算法改善了什么、退化了什么、是否允许进入下一组合。

最终候选不以功能最多或残差最小为唯一目标，而以证据完整、低黏度稳定、自由表面可信、误差有界、修正透明和性能可接受为目标。论文 HOME-Free 可以作为稳定基线长期保留；PLIC、投影、复杂 topology 和 FSI 只有通过同一 Dam-break 横向对照，并证明综合视觉/数值/性能收益后才获得集成资格。
