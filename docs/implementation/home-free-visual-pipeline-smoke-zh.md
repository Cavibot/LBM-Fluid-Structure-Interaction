# HOME-Free dam-break 视觉缺陷与流程烟雾验收

## 1. 本轮目标

本轮只验证 HOME-Free 离线演示链路可以从头到尾执行：数值模拟、原子快照、临时表面、RTX 5090 Blender/OptiX 渲染、结果回传、清单与哈希检查。它不替代 L1/L2 数值验收，也不表示当前表面质量或长时间稳定性已经合格。

### 2.1 分类与处置原则

- **已修复回归项（V01--V05）**：属于坐标映射、相机和诊断场景错误。本轮必须由自动检查持续守住，任何一项复现都判定流程失败。
- **已知预览限制（V06）**：临时 Marching Cubes 只能用于观察状态演化，圆角和接触边外观不能作为最终表面质量证据。
- **待优化物理问题（V07）**：侧壁退湿必须保留在图像中供诊断，禁止通过裁切、改角度或遮挡使其不可见。
- **已修复数值项（V08）**：原始失败值已形成回归，修复后 L1 越过旧失败时间窗并完成 3200 步；短程视觉运行本身仍保持 `numerically_qualified=false`，不能借用后续数值结果改变旧 manifest。

### 2.2 本轮自动视觉几何门槛

除文件与设备检查外，验证器还必须确认：水体位于水槽平面范围内；水体下界接触槽底；重力在相机空间中向下；水槽框在 X/Z 投影上包围槽内区域；正交视野不会裁掉水槽框。上述检查针对用户实际发现的方向、包裹和底部假缝问题，不尝试用像素启发式替代物理质量验收。

## 3. 流程烟雾验收

一次合格的流程烟雾运行必须满足：

1. 模拟从零开始并完成所有请求步；清单包含 `simulation_complete=true`。
2. 每个请求步都生成 NPZ、OBJ、PNG 和 Blender 日志。
3. NPZ、OBJ、PNG 的 SHA-256 与清单一致。
4. Blender 日志确认使用 RTX 5090 OptiX。
5. 水体世界包围盒位于模拟域内。
6. 相机前向为 `+Y`，屏幕上方为 `+Z`。
7. PNG 为 960x540、非黑屏且具有有效像素方差。
8. 至少两个输出帧时，水体前沿必须向下游推进。
9. 清单必须保持 `numerically_qualified=false`。

验证命令：

```bash
PYTHONPATH=. python scripts/render/home_free/verify_preview.py --run /path/to/run
```

`--allow-partial` 仅用于检查失败前已提交的调试产物，不构成流程烟雾通过。

## 4. 后续严格工作

流程打通后按原计划恢复数值研发：跨宽度周期的准二维 dam-break 已建立保守流程基线；下一步仍需单独修复三维侧壁润湿与接触线、低黏度细网格 kinetic mode，并用固壁感知 PLIC 表面替换临时 Marching Cubes。只有目标 Reynolds 数下的 L1/L2 数值门槛、表面质量和关键场景图片全部通过后，才可标记最终场景完成。

## 7. 2026-07-20 三层严格流程基线

### 7.1 配置与初始化修正

- dam-break 使用周期展向 `(False, True, False)`，因此该基线不声称解决 V07 的真实侧壁接触线。
- L0/L1/L2 的 `dx` 分别为 `1/0.5/0.25`，扩散缩放 `dt` 分别为 `0.5/0.125/0.03125`，总物理时间均为 400。
- 初始柱宽和高度统一为 `8.125`。原值 `8.25` 在 L2 上恰好落于单元面，只生成 `fill=0/1` 并造成 9360 条液气直连；新值在三层分别保留 `0.125/0.25/0.5` 的真实部分填充界面。单测同时检查界面非退化和物理体积一致。
- 本轮只为打通严格工作流，采用物理黏度 `0.10`；三层格点黏度固定为 `0.05`、`tau=0.65`。这是一套保守基线，不是目标高 Reynolds 配置。

### 7.2 已修复的运行期缺陷

1. 守恒几何闭包原先拒绝恰好落在 `fill=0/1` 的合法端点；现允许闭区间端点，并由液气分离修复恢复必要的 interface 层。
2. PLIC 近轴法向量的降维顺序不一致会产生超过 donor fill 的面通量；现统一为先降维、后按 Courant 缩放扫掠薄片。
3. 周期展向 topology partner 原先按绝对线性索引选取，破坏平移等变性；现按相对距离和相对偏移确定，L0/L1/L2 全程展向 fill range 均为精确零。
4. 失败 runner 现在保存候选 OM 状态及最大速度单元、矩、fill、flag 和邻域，可区分已提交缓冲与失败候选缓冲。
5. dam-break 静止判定原先硬编码格子速度 `0.005`；现按 `u_physical=u_lattice*dx/dt` 判断，避免扩散缩放下误判 L2。

### 7.4 尚未关闭的低黏度边界

- `nu=0.03, tau=0.545`：L1 在 `t=385.125` 于左下无滑移角点越过格子速度 0.12；放宽诊断上限后速度继续单调增长至 0.30，确认不是瞬时物理峰值。
- `nu=0.04, tau=0.56`：L2 在 `t=197.1875` 于推进液舌附近越过 0.12；质量、展向对称性和 topology 仍正常。
- `nu=0.06, tau=0.59`：L2 将失败延后至 `t>275`，但没有消除同类细网格模态。

这些失败证明当前 HOME 边界/自由表面稳定化尚不能覆盖目标高惯性 L2 工况。后续应针对无滑移角点和 interface kinetic mode 研究有论文依据的稳定化，不得通过提高速度上限、缩短终止时间或把 `nu=0.10` 的结果外推到低黏度场景来关闭问题。
